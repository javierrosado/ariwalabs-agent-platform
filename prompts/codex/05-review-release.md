# Prompt: revisar release

Realiza una revisión de release del agente `<AGENT_ID>`.

Verifica:

- definición;
- skills;
- schemas;
- workflows;
- handoffs;
- aprobaciones;
- políticas;
- pruebas;
- regresión;
- secretos;
- compatibilidad;
- documentación;
- changelog.

Genera:

- hallazgos por severidad;
- bloqueos;
- riesgos;
- acciones;
- versión recomendada;
- decisión `ready`, `ready_with_observations` o `blocked`.
