# Prompt: cargar contexto del proyecto

Analiza este repositorio de AriwaLabs antes de modificarlo.

1. Lee `README.md`.
2. Lee `shared/context/*.yaml`.
3. Lee `shared/policies/*.yaml`.
4. Lee el `agent.yaml` del agente afectado.
5. Lee sus skills, workflows, schemas y handoffs.
6. Identifica el componente del framework que debe modificarse.
7. No dupliques contexto institucional.
8. No conectes directamente una skill con un proveedor externo.
9. Conserva aprobación humana obligatoria.
10. Propón primero los archivos que modificarás y las pruebas que ejecutarás.

Entrega:
- entendimiento;
- impacto;
- archivos;
- riesgos;
- plan de pruebas.
