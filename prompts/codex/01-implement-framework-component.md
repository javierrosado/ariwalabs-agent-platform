# Prompt: implementar componente del framework

Implementa o mejora el componente `<COMPONENT>`.

Condiciones:

- mantener tipado estricto;
- usar interfaces/adapters;
- no acoplarlo a Growth & Marketing Agent;
- añadir validación de errores;
- añadir pruebas unitarias;
- actualizar documentación;
- mantener compatibilidad con la CLI;
- registrar eventos de auditoría;
- respetar las políticas globales.

Antes de terminar:

- ejecutar ruff;
- ejecutar mypy;
- ejecutar pytest;
- ejecutar validación del Framework Agent;
- resumir cambios y deuda técnica.
