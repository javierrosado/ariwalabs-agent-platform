# Prompt: crear un nuevo agente

Crea el agente `<AGENT_ID>` usando el AriwaLabs Agent Framework.

Debe incluir:

- `agent.yaml`;
- propósito y límites;
- perfiles de modelo;
- contexto compartido;
- skills;
- workflows;
- schemas;
- handoffs;
- puntos de aprobación;
- rúbricas;
- ejemplos;
- pruebas;
- documentación.

No copies los archivos de `shared/context`.
Referencia únicamente lo necesario.

Ejecuta el Framework Agent para validar la definición antes de declarar el
agente listo.
