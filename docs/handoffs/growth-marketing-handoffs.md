# Handoffs del Growth & Marketing Agent

## A Training Program Agent

Entrada requerida:

- `training_brief_id`
- nivel;
- segmento;
- problema;
- propuesta de valor;
- duración;
- modalidad;
- resultados esperados;
- restricciones;
- versión aprobada.

## A Student Success Agent

Entrada requerida:

- person_id;
- enrollment_id;
- cohort_id;
- estado;
- expectativas;
- datos de contacto autorizados;
- empresa y cargo, cuando hayan sido proporcionados voluntariamente.

## A Corporate Opportunity Agent

Solo después de aprobación:

- opportunity_signal_id;
- student_id;
- organization_id;
- señales observadas;
- necesidades hipotéticas;
- evidencia;
- confianza;
- restricciones de contacto;
- decisión del director.

## A Content Agent

- content_brief_id;
- campaña;
- audiencia;
- canal;
- formato;
- mensajes;
- CTA;
- fuentes;
- restricciones;
- fecha;
- estado de aprobación.
