# ADR-008: LinkedIn manual durante la primera etapa

Fecha: 2026-07-17
Estado: aceptada

## Contexto

LinkedIn sera un canal importante, pero publicar automaticamente aumenta riesgo
de reputacion, claims no revisados y errores de aprobacion.

## Decision

Durante la primera etapa, LinkedIn se manejara con publicacion manual a partir
de briefs o artefactos aprobados.

## Alternativas

- Integrar API de LinkedIn desde el MVP.
- Usar herramientas de publicacion automatica sin approval engine.
- No usar LinkedIn.

## Consecuencias

- Reduce riesgo de publicacion indebida.
- El agente puede preparar briefs, pero no publicar.
- La automatizacion social queda para una fase posterior.
